# Boobalan V — Developer Portfolio

Personal portfolio website built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion**, showcasing full-stack software engineering work, SaaS & ERP applications, personal projects, awards, and certifications.

## Tech Stack

- **Framework:** Next.js 15 (Pages Router)
- **UI & Styling:** React 18, Tailwind CSS v4, Framer Motion
- **Pages:** Home (`/`), About (`/about`), Projects (`/projects`), Credentials (`/articles`), Contact (`/contact`)

## Running Locally

```bash
npm install
npm run dev
```

Open [https://alanz-tech.netlify.app/](https://alanz-tech.netlify.app/) in your browser.
